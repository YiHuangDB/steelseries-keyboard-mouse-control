# Automation Scripts Documentation

This folder provides Windows batch scripts for quick one-click control.

## Scripts

- [turn_led_off.bat](turn_led_off.bat): Executes `main.py --off` to start the silent background controller and turn off keyboard/mouse LEDs.
- [turn_led_on.bat](turn_led_on.bat): Executes `main.py --on` to stop the background daemon and restore default RGB lighting.
